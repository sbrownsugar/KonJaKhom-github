## ระบบนี้ทำอะไร

คัดกรองว่านักเรียนคนใด **สัมผัสปัจจัยเสี่ยง** ที่งานวิจัยเชื่อมโยงกับอาการปวดคอ-บ่า-หลัง
มากน้อยเพียงใด แล้วชี้ว่า *"ใครควรได้รับการดูแลต่อ"*

**ระบบนี้ไม่วินิจฉัยโรค** และไม่บอกว่าใครกำลังปวดหรือจะปวด — ทำหน้าที่เหมือน
เครื่องวัดอุณหภูมิหน้าประตูโรงเรียน คือคัดกรองเพื่อส่งต่อ ไม่ใช่ผลตรวจ

---

## ข้อค้นพบที่เปลี่ยนโครงงานนี้ทั้งหมด

เราตั้งต้นจะทำ AI ทำนายอาการปวดจากท่าทาง **แล้วพบหลักฐานว่าทำไม่ได้**

| หลักฐาน | ผล |
|---|---|
| Raine Study (Physical Therapy 2021, n=686, ตามตัวจริง 17→22 ปี) | ท่าค่อม/คอยื่นตอนอายุ 17 → OR 0.24 (95% CI 0.08–0.76) = odds **ต่ำกว่า** คนนั่งตัวตรง |
| Mahmoud 2019 (meta-analysis) | ในวัยรุ่น มุม CVA ของคนปวดกับไม่ปวดต่างกัน 1.05° (95% CI −4.23, +2.12) = ไม่มีนัยสำคัญ |
| งานเกาหลี (n=531, ภาพ 4K, ResNet50) | ทำนายอาการปวดจากภาพได้ AUC 0.611 = เกือบเดาสุ่ม |

**เราจึงกำหนดให้น้ำหนักของมุมท่าทางทุกตัวในดัชนี = 0 ด้วยมือของเราเอง**

> **"ถ้าลบ MediaPipe ออกทั้งหมด ดัชนีความเสี่ยงเปลี่ยนไหม"**
> **ไม่เปลี่ยนครับ — และนั่นคือสิ่งที่หลักฐานสั่งให้เราทำ**

AI ในระบบนี้จึงไม่ใช่ **ตัวทำนาย** แต่เป็น **เครื่องมือวัด** ซึ่งเป็นบทบาทเดียวที่หลักฐานรองรับ
แบ่งหน้าที่ชัดเจน: **AI = ตัววัด · แบบสอบถาม = ตัวประเมินความเสี่ยง**

## ดัชนี RFEI — เปิดให้กดเครื่องคิดเลขตามได้ทุกบรรทัด

    RFEI = exp( λ · Σ βᵢ · (xᵢ − cᵢ) )     โดย λ = 0.6

- `cᵢ` = โปรไฟล์อ้างอิงที่เรานิยามเอง → คนที่มีค่าเท่าโปรไฟล์อ้างอิงทุกตัวจะได้ RFEI = 1.00 พอดี
- ค่า β ทุกตัวมาจาก **งานวิจัยที่ตีพิมพ์แล้ว ไม่ได้เทรนจากข้อมูลนักเรียนของเรา**
  (เพราะ n ของเราน้อยเกินกว่าจะเทรนอย่างซื่อสัตย์ได้)
- ค่า `cᵢ` ทั้งหมดและวิธีเข้ารหัสทุกตัวแปร อยู่ใน `project/src/scoring.py`

| ตัวแปร | β | ที่มา |
|---|---|---|
| เคยปวดใน 12 เดือน | 1.33 | Raine 2021, OR 3.78 |
| ความเครียด/อารมณ์ | 0.74 | Gao 2023 meta, n=18,395, OR 2.09 |
| ออกกำลังกาย < 2 วัน/สัปดาห์ | 0.63 | Gao 2023, OR 1.88 |
| เพศหญิง | 0.52 | Gao 2023, OR 1.69 |
| นอน < 7 ชม. | 0.46 | Auvinen 2010, OR 1.58 |
| นั่ง ≥ 6 ชม./วัน | 0.23 | Meng 2025 |
| ก้มมือถือ (ต่อชั่วโมง) | 0.215 | SR+MA 2025, OR 1.24 |
| BMI เกิน | 0.17 | Nature 2024, OR 1.18 |
| **มุมท่าทางทุกตัว** | **0** | Raine 2021 / Mahmoud 2019 = null |
| **น้ำหนักกระเป๋า ≥ 10%** | **0** | Calvo-Muñoz 2020, IPD n=9,188 = null |

## ข้อจำกัดที่เราประกาศเอง

1. **ไม่วินิจฉัยโรค** และบอกไม่ได้ว่าใครกำลังปวด (ความปวดมองไม่เห็นจากภาพ)
2. **ดัชนี RFEI ยังไม่เคยถูก validate** กับผลลัพธ์จริง เราจึงไม่เรียกมันว่า "คะแนนความเสี่ยง"
3. **λ = 0.6 เราตั้งเอง** เป็น heuristic ชดเชยการนับซ้ำ ไม่ใช่ค่าที่ประมาณจากข้อมูล
4. **β ทุกตัวเป็น odds ratio ไม่ใช่ risk ratio** เมื่อความชุกสูง (39.7–44.7% ในวัยรุ่นไทย)
   OR จะเกินจริงกว่า RR มาก เราจึงใช้คำว่า *"odds เทียบกับโปรไฟล์อ้างอิง"* เสมอ
   และ **ไม่เคยใช้คำว่า "เสี่ยงกว่าเพื่อนกี่เท่า"** ทั้งในเอกสารและบนหน้าจอ
5. **MediaPipe ไม่มีจุด C7** มุมที่ได้จาก landmark ล้วนจึง **ไม่ใช่ CVA** เราเรียกตามความจริงว่า
   **"มุมหู–ไหล่"** ซึ่งไม่มีค่ามาตรฐานที่ตีพิมพ์ → ระบบ **ไม่ตัดสินว่าปกติ/ผิดปกติ**
   และ **ไม่มีแถบสีสำหรับมุมท่าทาง** ตัวเลขมีไว้ให้ผู้ใช้เทียบกับตัวเองในอนาคตเท่านั้น
6. **ธงความไม่สมมาตรของเราไม่ใช่ ATR** ที่วัดด้วย scoliometer จึงยังไม่มีค่าทำนายบวกของตัวเอง
   และแม้แต่เกณฑ์มาตรฐาน ATR ≥ 5° ยังมีค่าทำนายบวกเพียง 28.3% → **ธงแดงส่วนใหญ่ไม่ใช่โรค**

## ความเป็นส่วนตัว

- ประมวลผลบนเครื่อง **ไม่ส่งภาพออกนอกเครื่อง** ไม่ใช้เซิร์ฟเวอร์ภายนอกใด ๆ
- เก็บเฉพาะ **ตัวเลขมุม** ภาพถูกแปลงเป็นตัวเลขแล้วลบทิ้งทันที ไม่เก็บลงฐานข้อมูล
- ใบยินยอมจากนักเรียน**และ**ผู้ปกครองก่อนถ่ายทุกคน ถอนตัวได้ทุกเมื่อโดยไม่ต้องให้เหตุผล
- นักเรียนเห็นผลของตนเองก่อนเสมอ และเลือกได้ว่าจะให้ครูอนามัยเห็นหรือไม่
- ระบบไม่แสดงถ้อยคำเกี่ยวกับรูปร่างหรือน้ำหนักตัวต่อนักเรียน (ลดความเสี่ยงต่อพฤติกรรมการกินผิดปกติ)
- **ซอร์สโค้ดชุดนี้ไม่มีภาพของบุคคลจริงแม้แต่ไฟล์เดียว** โดยเจตนา
